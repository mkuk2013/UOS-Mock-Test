Supabase Free Database Setup

1 Minute mein Cloud Database banayein

1

Supabase Account & Project Kholein:

supabase.com par jayein (Free Account) aur "New project" banayein.

2

SQL Editor Mein Table Banayein:

Left menu se "SQL Editor" par jayein, "New query" dabayein aur yeh script paste karke Run karein:

create table if not exists uos_mock_users (
  id text primary key,
  username text unique not null,
  password text not null,
  boundDeviceId text,
  status text default 'active',
  createdAt text,
  lastLogin text
);

alter table uos_mock_users disable row level security;
3

API Keys Copy Karein:

Project Settings ➔ "API" tab par jayein. Project URL aur anon public key copy karke yahan input boxes mein paste karein aur "Connect Cloud" dabayein!
